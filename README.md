## 🌟 Modules & Future-Level Capabilities

### 1. 🏠 Dashboard
- **5 Core KPI Cards**: Total Links, Total Clicks (+28% velocity), Active Links, Unique CTR (83%), Top Performing Asset.
- **Velocity Tracker Chart**: Interactive 7-day click trajectory curve.
- **Referrer Attribution**: Instagram (38%), WhatsApp (31%), Twitter/X (16%), LinkedIn (9%), Direct (6%).
- **Geo Distribution**: Country breakdowns with flags and progress bars (India, US, UK, Germany, Singapore).
- **Live Click Telemetry Feed**: Real-time ticker dispatching events with device icons and location tags.

### 2. 🔗 Create Link Studio (Advanced)
- Destination URL input with protocol auto-formatting.
- **AI Auto-Fill Title & Tags**: Extracts metadata and assigns high-conversion SEO titles.
- **AI Suggested High-CTR Aliases**: Generates memorable viral aliases with CTR prediction badges (e.g. `+32% CTR`).
- **Smart Expiry Recommendation**: Explains optimal campaign window to trigger FOMO.
- **Password Gate Protection**: Restrict sensitive destinations with access PINs.
- **UTM Parameter Builder**: Quick presets for Instagram Bio, WhatsApp Blast, and Google Ads.
- **Geo-Routing & A/B Split Testing Toggles**: Arm advanced routing rules directly during creation.

### 3. 🧾 Link Control Center
- Full data inventory table with instant search and status filters (Active, Disabled, Expired).
- **Instant Status Toggle**: 1-click enable/pause for any link.
- **Bulk Action Bar**: Select multiple links to bulk activate, disable, archive, tag, or delete.
- **Git-like Version History Audit Log**: Inspect timestamps and parameter change logs.
- **Interactive QR Modal & Delete Confirmation**: Prevents accidental deletions.

### 4. 📊 Deep Analytics Lab
- Individual link selector or portfolio view.
- **Hardware & Browser Telemetry**: Mobile (65%), Desktop (29%), Tablet (6%), Chrome, Safari, Firefox, Edge.
- **24-Hour Activity Heatmap**: Identifies peak engagement windows (peak: 18:00 - 21:00).
- **Side-by-Side Link Comparison Benchmark**: Computes delta percentage between 2 links.
- **AI Anomaly Detection Alert**: Automatically flags traffic surges or channel drops.

### 5. 🤖 AI Intelligence Hub (Project Highlight)
- **Link Health Index**: Score out of 100 based on CTR, mobile friendliness, and UTM tagging.
- **Best Time to Share**: Identifies peak days and hour windows with strategic reasoning.
- **Audience Persona Analysis**: Discovers whether visitors are mobile chat scrollers or desktop professionals.
- **Bottleneck Diagnosis ("Why Link is Underperforming")**: High mobile drop-off detection, dark traffic attribution, and actionable fixes.
- **Actionable Suggestions to Improve Clicks**: Specific recommendations with expected lift metrics (`+34%`, `+19%`, `+28%`).
- **Predict Future Clicks**: 7-day and 30-day predictive growth modeling with confidence scores.
- **Multi-Channel Auto Campaign Copywriter**: Ready-to-copy posts for Instagram, WhatsApp, LinkedIn, and Twitter with link embedded.
- **AI Link Copilot (Conversational Chatbot)**: Ask any natural language question about links, timing, or growth strategies.

### 6. ⚡ Automation Engine
- **Event-Driven Rules**:
  - `IF clicks > 1000` → Send in-app notification / alert.
  - `IF link expired` → Auto-renew expiry by +30 days.
  - `IF country == IN` → Trigger regional webhook payload.
  - `IF spike detected` → Auto-pause or dispatch webhook.
- **Webhook Dispatcher Console**: Test payloads with real HTTP status codes and response latency.
- **Execution Audit Trail**: History of all rule firings.

### 7. 🎨 QR Studio
- Custom foreground and background hex color pickers + 4 neon presets.
- Geometry dot styling: Rounded Dots, Square Grid, Smooth Circles.
- Center emblem badge toggle.
- **QR Scan Telemetry Tagging**: Distinguishes print/offline scans (`?src=qr`) from web link clicks.
- Ultra-res PNG and SVG downloads.

### 8. 🔀 Smart Redirect & A/B Split Testing Studio
- **Geo-Routing Rules**: Redirect Indian visitors to Razorpay/INR pages and US visitors to Stripe/USD pages.
- **A/B Split Testing Engine**: 50/50 or custom traffic split between two landing pages with winner detection.
- **Interactive Edge Simulator**: Test and verify redirect destinations for any simulated country IP.

### 9. 📁 Data Export Center
- Raw telemetry CSV export.
- Formatted Microsoft Excel (XLSX) workbook.
- Printable Executive PDF Intelligence Report preview.
- **Scheduled Automated Reports**: Configure daily, weekly, or monthly report emails.

### 10. 🔌 Developer API Portal
- Interactive REST testing sandbox for `POST /api/links/`, `GET /api/analytics/link/:id/`, and `POST /api/ai/insights/`.
- Code snippets in **cURL**, **Python Requests**, and **JavaScript Fetch**.

### 11. 👤 User Settings & Team
- Profile management with avatar and company name.
- **Secret API Keys**: Generate secure `lk_live_...` tokens, view usage, and revoke keys.
- **Team Collaboration & Roles**: Invite teammates as Admin, Editor, or Analyst.
- **SaaS Pricing & Limits Matrix**: Free ($0), Pro ($29), Enterprise Cloud ($149).

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Canvas-Confetti, PostCSS.
- **Backend**: Python 3.12, Django 5.0, Django REST Framework, Django CORS Headers.
- **Database**: SQLite3 (PostgreSQL-ready with indexed models).
- **AI Engine**: Neural heuristic pattern analyzer, click velocity projection, campaign generator, and interactive copilot.
- **Security**: Token-based authentication, password-protected link gates, and request isolation.
